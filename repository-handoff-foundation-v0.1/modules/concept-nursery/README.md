# Concept Nursery

This directory gives useful possibilities a calm place to rest until another
observation, owner choice, or receiving use makes their next form clear.

An entry belongs here when it can inform later work and still awaits a current
outcome, acceptance signal, or authority grant. Active work belongs in a
GitHub Issue. Supplied source material belongs in `references/`. Settled
rationale and recovery coordinates belong in `threadkeeping/`.

## Entry shape

Use one Markdown file per concept and include:

```markdown
# Concept title

## Useful possibility
What condition could this create, and for whom?

## Present evidence
What source, observation, or practitioner experience makes it worth keeping?

## Open decision
What remains unknown or human-held?

## Return signal
What observable event would make this timely?

## Possible receiver
Which Issue, source owner, or person could receive it next?
```

## Revisit with a disposition

When the return signal appears, choose the smallest fitting destination:

- promote the concept into one outcome-bearing Issue;
- connect it to an existing Issue or reference record;
- keep it resting with a revised return signal;
- fold it into a clearer existing owner; or
- retire it while preserving any rationale that will help a future reader.

The Nursery records possibilities at rest. A named return signal keeps that
rest compatible with later movement.
