# References

This directory keeps supplied material close to the decision it can inform
while preserving provenance, access boundaries, and source authority.

- `public/` receives material that is safe to retain in repository history.
- `local/` receives access-controlled working material and is ignored by Git
  except for its ignore rule.

A reference can inform orientation, a probe, or an Issue. Runnable source and
accepted Issues retain implementation authority.

## Intake record

For each retained reference, record the smallest useful context in a nearby
Markdown file or the receiving Issue:

- stable title or semantic key;
- origin and observed date or revision;
- public URL or authorized resolver, when one is safe to retain;
- relationship to maintained source;
- the current reader job or decision it can support;
- evidence limit or activation condition; and
- responsible receiver.

Keep credentials, signed links, private routes, and account-held identifiers
inside their authorized system. The repository can retain a public-safe key,
bounded description, and exact owner action for recovery.
