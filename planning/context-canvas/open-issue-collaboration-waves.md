## Cross-origin serving collaboration

### Current Cloudflare reading

- Workers Static Assets can deploy HTML, JavaScript, CSS, images, and a Worker script as one versioned unit with global caching.
- A Worker can return a complete HTML response; client scripts then run under ordinary web-platform and response-header rules.
- A `workers.dev` route fits an initial exploratory deployment. A Worker route or Custom Domain fits a production receiver.
- Each code or configuration change creates a version. Upload and deployment can be separate operations.
- Waiting on network I/O sits outside request CPU accounting. Current plan and platform limits remain a deployment-time reading.
- WebSockets are available in Workers. Durable Objects add coordinated state, hibernation, and SQLite-backed storage.
- Static Assets works independently of KV or D1. A real persistence requirement can select KV, D1, R2, or Durable Objects.

Earlier exploration notes about duration, WebSockets, storage, and response size are superseded by these current official readings:

- [Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/)
- [Workers limits](https://developers.cloudflare.com/workers/platform/limits/)
- [`workers.dev`](https://developers.cloudflare.com/workers/configuration/routing/workers-dev/)
- [Custom Domains](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/)
- [Versions and deployments](https://developers.cloudflare.com/workers/versions-and-deployments/)
- [WebSockets](https://developers.cloudflare.com/workers/runtime-apis/websockets/)

## Handoff shape

Each collaboration handoff makes five things easy to find:

1. the visitor condition to create;
2. the smallest relevant source boundary;
3. two or three implementation options with one current leading route;
4. what a visitor or collaborator can observe afterward; and
5. related work and the next return point.

This handoff shape preserves flexible review. A receiving collaboration owns the immediate work, a pull request owns the proposed diff, and named human collaborators retain consequential decision authority.

When one collaboration materially changes whether another can begin or settle, [Issue Chain stewardship](../../.agents/skills/issue-chain-stewardship/SKILL.md) adds the smallest useful route: current front, evidenced relation, pass condition, next receiver, and release event. Parallel and optional terrain stays visible, and each receiver retains its own contract.
