## First-pass questions

1. **Visitor job:** What should the visitor understand or do after following the reference?
2. **Source standing:** Is there an existing Registry destination, an adaptable source, a source-local account, or a question that still needs settlement?
3. **Portable meaning:** Which claim, distinction, example, recovery pattern, or evidence boundary materially supports the Context Canvas passage?
4. **Route shape:** Does the visitor need a Registry page, a stable detail section, an overview with detail, a Context Canvas explanation, or a deferred route?
5. **Re-entry:** Which source, destination, evidence, or audience change would reopen the decision?

A clear answer to these five questions is sufficient for a first route. Additional structure enters when it changes the destination or public wording.
