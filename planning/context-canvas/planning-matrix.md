## Practitioner-probe reading

For each row, the reusable probe is:

1. **Question** — what consequential behavior or boundary is under review?
2. **Why it matters** — which collaborator, visitor, or receiving system bears the effect?
3. **Mechanism** — what browser, cascade, schema, origin, build, or organizational behavior causes it?
4. **Observable evidence** — what local or remote result would distinguish the possibilities?
5. **Instruction yield** — what should the next collaborator do differently because this is known?

This keeps the matrix technical, practical, and oriented toward consequential decisions.
