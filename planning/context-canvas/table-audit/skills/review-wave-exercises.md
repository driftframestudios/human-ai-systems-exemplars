## Checkpoint boundary exercise deck

1. Change only an assertion's data dependency or loaded stylesheet. The relevant
   observation reopens; an unrelated complete case remains available for reuse.
2. Remove the inspector transition while retaining the visible prompt. The
   material-behavior assertion identifies the missing transition.
3. Provide matching text in a different static row. Exact-record parity still
   identifies the owning row's discrepancy.
4. Interrupt after a screenshot but before case publication. Complete earlier
   cases remain available and the interrupted case remains incomplete.
5. Finish all produced cases while omitting one required case. Campaign completion
   remains pending against the frozen requested inventory.
6. Change a source during a run. Publication uses a validated immutable input
   generation or returns the changed observation for re-entry.
7. Change an observation definition. Earlier evidence remains historically valid
   for its stated scope and earns fresh evidence for the new scope.
