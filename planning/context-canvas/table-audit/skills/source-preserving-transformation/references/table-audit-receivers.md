## Decision-changing local boundaries

| Input or event | Receiving distinction |
| --- | --- |
| A raw-text opening uses self-closing syntax | Admission preserves the text boundary by returning an unsupported-input outcome before projection. |
| Removing the sole data cell leaves a header-only row | Shape validation still covers the row; output derivation retains its established selection policy. |
| A caption repeats across many records | Aggregate expansion is admitted before repeated label strings and replacements are materialized. |
| Native duplicates appear on an unselected table | Selection preserves that owner's opaque subtree; ambiguity naming a selected family receives its own disposition. |
| Attribute scanning advances through many small tokens | Index progress and copied-character work are separate terms in the resource claim. |

Focused regressions, exact outside-edit comparison and the declared three-family
source/projection observation establish different boundaries. Shared Surface's
runtime-generated tables retain their browser/material receiver. The exercise
record preserves current results without turning the case count into a general
parser, accessibility or ingestion claim.

## Authority and release

Parser comparison remains a future adoption route. lxml or html5lib migration
requires an explicit output-contract decision and fitting comparative evidence.
Source edits, per-asset publication and broader repository delivery retain their
authorized owners. The local binding releases with the parent's bounded
acceptance or a named grammar/publication question; a new counterexample can
reopen the root contract without reopening every family.
