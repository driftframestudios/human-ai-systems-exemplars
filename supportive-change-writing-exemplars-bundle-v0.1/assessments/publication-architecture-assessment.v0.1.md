# Publication architecture assessment

## Probability referent

Each value estimates the chance that an architecture best preserves tone fidelity, conceptual granularity, contextual linkage, evidence status, material design character, and long-horizon usefulness for a hybrid human–AI team. The values are editorial planning judgments whose options sum to one within each decision set.

## Decision set 1 — content architecture

| Architecture | Probability | Salient quality |
|---|---:|---|
| Self-contained writing exemplar collection | 0.55 | Strong local context, coherent navigation, and durable identity |
| Distributed repository libraries | 0.30 | Broad reuse across existing categories |
| Monolithic dossier | 0.15 | Strong linear reading experience |

**Synthesis:** Use a self-contained collection whose main entry leads with writing and whose secondary reference layer carries YAML, schemas, registries, and editorial assessments.

## Decision set 2 — PDF publication architecture

Here the probability referent is the estimated chance that an architecture best supports depth, comparative literacy, navigability, contextual adaptation, and preservation of each essay’s identity.

| Architecture | Probability | Disposition |
|---|---:|---|
| Branch readers plus a complete anthology | 0.60 | Selected |
| One anthology with a narrower branch selection | 0.25 | Contextual alternative |
| Standalone essay PDFs | 0.15 | Contextual alternative |

**Synthesis:** Preserve the complementary essay postures within coherent branch readers and provide one anthology for comparative travel.

## Interstitial 1 — repository placement

| Placement | Probability | Salient quality |
|---|---:|---|

| Field Guide collection | 0.18 | Strong guidance adjacency |

**Reevaluation:** The root-level collection keeps the writing together while linking to the named Field Guide guidance.

## Interstitial 2 — original-brief fidelity

The review returned to the commissioned audience, testimonial formats, branch intentions, tone readouts, essay postures, evidence expectations, probability referents, PDF constraints, YAML front matter, schemas, contextual links, and negation-aware instruction guidance. ## Interstitial 3 — repository simplicity

The reader path now leads with the writing, PDFs, tone goals, and essay relationships. Schemas act as permissive descriptions. Registries act as compact discovery maps. Git history carries revision history, while direct context notes carry the material source boundary.
