Source note

    
This prototype is based on the stabilized Participatory Design Kit: Tacit Workflow Elicitation Kit card. It includes the Gantt, Masonry, Boolean, and Given / When / Then sub-surfaces described in the Core Architectures source material. The in-session visual reference image was used only as private collaboration reference for Gantt-like aesthetic rhythm and did not introduce human names or faces into this generated artifact.

    
The local recipe treats these surfaces as conversation instruments: participants can correct, move, split, duplicate, phase, annotate, and route the artifact so lived workflow becomes visible.
