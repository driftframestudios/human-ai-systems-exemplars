# Comparative Literacy Charter

The program uses a complete simulated final state to make expectations,
assumptions, and predicted effects inspectable before corresponding actual
results arrive.

Comparison remains three-way:

1. the released specification states required meaning;
2. the simulation demonstrates one coherent, falsifiable realization;
3. the actual implementation supplies observed behavior and constraints.

The comparator explains each material difference. Actual behavior can
corroborate the simulation, improve upon it, reveal a simulation correction,
surface a shared specification ambiguity, or leave evidence open.

Two simulation lanes preserve learning integrity:

- immutable forecast releases retain the view available before observation;
- current-best releases incorporate later evidence through successor decisions.

Simulation fidelity earns its maintenance cost when it moves material learning
earlier, clarifies an acceptance question, or produces a reusable scenario.
