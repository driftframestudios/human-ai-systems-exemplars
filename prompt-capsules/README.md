# Prompt Capsules

Prompt Capsules carry the smallest useful collaboration context from a source
artifact into a readable, copyable, versioned Markdown handoff. The source
artifact keeps authority for its state. A capsule is a projection—a derived
view rather than the source of truth—that names its source, state identity,
evidence boundary, requested return, and recovery route.

Start with the [Prompt Capsule 0.1.0 contract](0.1.0/prompt-capsule-contract.md).
Its [Strategy Canvas example](0.1.0/examples/strategy-canvas.md) is generated
from the canonical default state and checked by that artifact’s builder and
focused unit contract.

The [classified inventory](prompt-capsule-inventory.v0.1.0.md) distinguishes
canonical sources, maintained projections, historical versions, generated
receivers, and independently governed capsule families. It is an ownership map,
not a count of matching words.

The current adoptions span six Core source families: PODA v0.1.4, Alignment
Worksheet v0.1.4, Impact Map v0.1.5, Context Tree v0.1.7, Strategy Canvas
v0.2.4, First Responsible Version Matrix v0.1.4, Upstream Revision Loop v0.1.4,
Recovery Routing Atlas v0.1.4, Participatory Design Kit v0.1.4,
Specification-by-Example v0.1.6, Pattern–Problem Surface Matrix v0.1.4,
Jobs-to-be-Done Treemap v0.1.4, Unit-test-first Design v0.1.4, HEART Chart
v0.1.6, Plus / Delta v0.1.4, and Practitioner Judgment Probes v0.1.4; all four
current Narrative Architecture sources; and two standalone instruments—Open
Lesson Field and Cross-Functional Investment Model Studio. The sixteen Core
adoptions complete the current Orientation and Tracing, Comparison and
Threshold, Recovery Routing and Revision, Participatory Elicitation and
Specification, Pattern Fit and Behavior Protection, and Measurement,
Reflection, and Judgment families.
Each source owner keeps its own state and schema version while
projecting complete plain and skill-assisted Markdown views with one
represented-state fingerprint. Each source points to a small set of related
collaboration loops whose fit conditions remain visible.

Open Lesson Field derives both GitHub Flavored Markdown views from its accepted
v2 lesson state. Copy and download return the selected view exactly, Related
loops remain native page content, and lesson assembly keeps a reviewed snapshot
available for recovery. Cross-Functional Investment Model Studio derives one
complete handoff from the fixed scenario and selected method while people retain
economic inputs and decision authority. Narrative Capsule Composer, Semantic
Sampling, Technology Fit, and Threadkeeping Ledger derive the same exchange
shape from their distinct accepted states. PODA carries its purpose,
objectives, discoverables, activities, and accepted handoffs. Alignment
Worksheet keeps forward and backward premises together with its option spread
and evidence. Impact Map carries every actor-to-impact-to-discoverable trace.
Context Tree carries every role, context question, cell, status, and handoff
route while focus remains presentation state. First Responsible Version Matrix
derives the exchange from its complete card set, active focus view, threshold
placements, evidence statuses, handoffs, review triggers, semantic guidance,
and recovery route. Upstream Revision Loop carries each downstream observation,
prior and revised read, revision target, status, route, and AI context update.
Recovery Routing Atlas carries all recovery geometries,
their strain and restoration readings, primary and secondary routes, recovery
moves, evidence, status, and focus-view standing. Participatory Design Kit
carries the workflow’s lanes, phases, activities, materials, and example
fragments. Specification-by-Example carries the complete rule and scenario
catalog with each Given / When / Then outcome. Pattern–Problem Surface Matrix
carries eight patterns, six population groups, and all 48 described
relationships. Jobs-to-be-Done Treemap carries each job’s purpose, weight,
drivers, evidence, status, route, and review trigger. Unit-test-first Design
carries each protected behavior’s source, preconditions, action, expected
results, platform-independent test target, and evidence route. HEART Chart
carries every goal, signal, counter-signal, metric, threshold, and action
route. Plus / Delta carries every observation with its reflection kind, goal,
actor, evidence, status, instruction, review trigger, and route. Practitioner
Judgment Probes carries every question with its probability target and
estimate, concern family, causal path, evidence standing, instruction yield,
and route. Other capsule-bearing artifacts keep their existing contracts until
their source owner accepts a migration with a material use and fitting tests.
