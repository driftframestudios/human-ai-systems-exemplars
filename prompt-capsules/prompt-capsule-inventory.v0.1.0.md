# Prompt Capsule inventory

- Inventory version: `0.1.0`
- Contract in active pilot: [`prompt-capsule/0.1.0`](0.1.0/prompt-capsule-contract.md)
- Classification basis: semantic ownership and projection role, not matching words

This inventory routes work to the source that can accept it. The observed
current population contains 28 source artifacts: 21 listed as current by the
Core manifest, four listed as current by the Narrative manifest, and three
directly maintained standalone artifacts. Strategy Canvas v0.2.4, First
Responsible Version Matrix v0.1.4, Upstream Revision Loop v0.1.4, Recovery
Routing Atlas v0.1.4, Participatory Design Kit v0.1.4,
Specification-by-Example v0.1.6, Pattern–Problem Surface Matrix v0.1.4,
Jobs-to-be-Done Treemap v0.1.4, Unit-test-first Design v0.1.4, the four current
Narrative Architecture sources, Open Lesson Field, and Cross-Functional
Investment Model Studio are the fifteen current adoptions. The remaining 13
sources keep their accepted capsule behavior until their owner has a receiving
use and fitting migration evidence.
Later adoptions retain this 28-source denominator; their manifest rows name the
accepted sources without counting companion projections or generated archives
as new sources.

## Promotion route

Another artifact joins this contract when its owner can produce both views from
one accepted state, keep the fingerprint independent of view, preserve its
source-owned state and recovery behavior, supply a readable no-JavaScript
default, and protect active-view byte agreement with focused tests. Until then,
its existing capsule remains the truthful current behavior.
