## Shared embedded-SVG grammar

- A stable semantic record is distinct from its view state. Canonical IDs and order remain stable while visibility, display order, selection, and frame order can change.
- Hiding is focus state, not deletion or redaction. Semantic removal is separate and confirmed.
- The HTML table is the complete reading and editing surface; SVG is a compact derivative generated from the same state.
- Explicit controls replace drag-and-drop: select/inspect, move earlier/later, hide/show, add, reset, and remove.
- Long text remains available through preview-and-reveal controls.
- The common envelope includes `artifact_identity`, domain records, `view_state`, `route_registry`, `semantic_locality`, and `recovery_calibration`.
- Domain records commonly preserve evidence status, route and route reason, review trigger, canonical order, and computed visible/display order.
- JSON and JSON-LD round-trip, an advanced identity registry, and a visible AI collaboration prompt are treated as first-class artifact surfaces.
- Stronger examples give SVGs a title and description, keyboard-selectable groups, Enter/Space handling, visible focus, and a full text/table equivalent.

For A3, this grammar should produce deterministic views of `LEGACY`, `SHADOW`, `DUAL-RUN`, `NEW`, `RETAINED LEGACY`, and `UNKNOWN`; typed connectors should distinguish `reads`, `mirrors`, `routes`, `authorizes`, `depends on`, and `rolls back`.

## Implementation gaps to resolve

- SVG keyboard operation, `<title>/<desc>`, and focus restoration after re-render are inconsistent across prototypes.
- Wide SVG minimum widths require a dedicated mobile/Notion poster mode.
- Print styling exists in many but not all artifacts; there is no shared SVG, PNG, or video export pipeline.
- CSS, route registries, render helpers, clipboard handling, and import normalization are duplicated.
- Imported JSON is permissively normalized without a formal versioned JSON Schema or migration layer.
- Some generated IDs are random or time-based.
- JSON-LD uses the placeholder namespace `https://example.org/core-architectures#`.
- There is no common reduced-motion animation pattern or persistent storage beyond exported files.
- The current parchment/gradient presentation is a skin; A3 should retain the operational grammar while applying the established flat cobalt, low-flourish, Bringhurst-informed art direction.
