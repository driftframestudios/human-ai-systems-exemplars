# A3 Stacked Cube Visual System Bundle v0.1

This self-contained exemplar turns the A3 strangler-fig model into an interactive authority storyboard and two static SVG readings. It keeps migration claims bounded: a cube is a software capability or service dependency, position shows current authority, and a transfer occurs only through a named seam, evidence gate, and rollback route.

## Open the prototype

Open `a3-stacked-cube-visual-system-chimeric-prototype-v0.1.html` in a current browser. No build step, server, external stylesheet, font, or JavaScript library is required. The canonical v0.1 model is embedded in the prototype so the controls and exports work from a local file.

## Semantic invariants

1. `UNKNOWN` remains a visible durable state, never an empty or negative value.
2. Human activity remains a workflow ribbon unless evidence establishes a bounded software capability.
3. Visible gaps imply verified separability; coupled or unbounded work remains linked, banded, or retained.
4. Color is redundant with label, shape, hatch, and line treatment.
5. F3 transfers authority only for the validated capability; retained legacy and rollback remain visible.
