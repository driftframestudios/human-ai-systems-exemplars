# Visual Fidelity Contracts

These compact contracts let a collaborator reproduce a visual language while
adapting the subject, composition, and level of detail to the page, diagram,
prototype, or decision setting at hand.

| Arriving with | Begin here | What becomes available |
| --- | --- | --- |
| A visual form that needs continuity with existing work | [Available contracts](#available-contracts) | Palette, typography, geometry, composition, and state guidance |
| A question about readable width or wide artifacts | [Shared reading measure](#shared-reading-measure) | Prose and two-dimensional layout guidance |
| A need to inspect working applications | [Reference implementations](#reference-implementations) | Source-owned HTML, CSS, SVG, and interactive examples |

The public [Visual Fidelity
Contracts](https://kindlight.systems/visual-fidelity-contracts) collection
supplies the wider orientation. [Visual Fidelity Practitioner
Probes](https://kindlight.systems/visual-fidelity-contracts/visual-fidelity-practitioner-probes-layered-judgment-evidence)
adds questions for extending a contract while preserving layered judgment and

## Shared reading measure

Every contract carries one reading posture across its variations. Sustained prose targets approximately 50–66 characters per line and usually remains within 75. The shared Context Canvas implementation uses `66ch` as a font-relative proxy, `58ch` for larger leads, and about `32ch` for ordinary standalone headings. The rendered typeface, language, spacing, and container padding determine the final line.

Wide space belongs to comparison, relationship, operation, and orientation. Tables, diagrams, prototypes, ledgers, and card grids may use editorial or wide canvases; their introductions, instructions, definitions, captions, notes, and evidence boundaries return to the reading measure. Narrative content reflows in the reading direction while a genuinely two-dimensional artifact carries its own local overflow. The supporting evidence and implementation seam are recorded in the [Context Canvas reading-measure research spike](../planning/context-canvas/reading-measure-research-spike.md).

## Viewlet composition posture

- Use leaf viewlets as a labeled vocabulary rail or copy selected geometry into an authored composite; keep the source package in place.
- A source leaf's state list names available states rather than reporting a current state. Authored surfaces must write the current state directly.
- Use the positive attention cue `ANOMALY · LOOK HERE`. Keep evidence, affected surface, and named receiver adjacent.
- Sequence labels name function and handoff. When an AI collaborator compares consequential alternatives, rotate presentation order and inspect whether the recommendation changes; long-context retrieval and LLM evaluation both show position effects ([Liu et al., 2023](https://arxiv.org/abs/2307.03172); [Wang et al., 2024](https://aclanthology.org/2024.acl-long.511/)).
- The twelve `speculative-ai` leaves remain visibly labeled as propositions. Visually similar geometry must retain its written role because shape alone cannot carry the distinction.
- Source leaves are static references. Any authored attention motion keeps the complete base state visible, uses slow transform/outline emphasis, and freezes under `prefers-reduced-motion`.

`Cobalt Evidence` remains the useful name for inspected relationship diagrams. `Cobalt Operating Field` extends that language to surfaces where people inspect state, act within explicit boundaries, and see the technical substrate and investment that make the work dependable.
