# Visual Fidelity Contracts

Visual Fidelity Contracts connect art direction with the behavior that makes an
interface dependable. Begin with the work a person needs to do, choose a visual
language, then follow its source, tokens, examples, and verification route.

The public [Visual Fidelity Contracts](https://kindlight.systems/visual-fidelity-contracts)
collection supplies the wider orientation. This repository maintains the
executable, versioned contract material listed here.

## Integrate and verify

1. Start from the actual operating object and population.
2. Select a contract by fit and smallest useful dose.
3. Map the reference tokens into the receiving component or route owner.
4. Preserve written state, focus, recovery, and semantic equivalents as the
   implementation changes shape.
5. Run the contract's focused source and browser observations.
6. Record the evidence established by each check and the receiving-system
   decision that remains with its owner.

The [public-lineage record](./publication/public-lineage.v1.json) separates
stable contract identity, repository source, and public retrieval. Public files
carry public routes and descriptions maintained in this repository. Private collaboration
identities and locators stay with their private owner.

### Shared reading measure

Sustained prose targets approximately 50–66 characters per line and usually
stays within 75. The rendered typeface, language, spacing, and container padding
determine the final line. Larger leads commonly use about `58ch`; ordinary
standalone headings commonly use about `32ch`.

Wide space belongs to comparison, relationship, operation, and orientation.
Tables, diagrams, prototypes, ledgers, and card grids may use editorial or wide
canvases. Their introductions, instructions, definitions, captions, notes, and
evidence boundaries return to the reading measure. Narrative content reflows in
the reading direction. A genuinely two-dimensional artifact keeps its geometry
inside a named local inspection region. The [reading-measure research spike](../planning/context-canvas/reading-measure-research-spike.md)
records the supporting evidence and implementation boundary.

## Re-entry

A changed contract meaning, palette value, public route, browser baseline,
accessibility requirement, or receiving-system authority reopens the fitting
contract and its focused observations. The catalog's `reviewedOn` date shows the
last repository review. Each downstream implementation establishes current
conformance through its own mapped contract and focused observations.
