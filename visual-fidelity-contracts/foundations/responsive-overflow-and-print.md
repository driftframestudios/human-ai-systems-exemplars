# Responsive overflow and print

Responsive composition preserves the decision while changing its arrangement.
Narrative and controls reflow in the reading direction. A genuinely
two-dimensional artifact keeps its relationships inside a named local inspection
region.

## Reflow at 320 CSS pixels

Test the artifact at a 320 CSS-pixel viewport, which also represents the common
1280 CSS-pixel viewport observed at 400% zoom. At that width:

- page-level horizontal overflow stays absent;
- headings, prose, controls, status, and recovery follow a deliberate source
  order;
- labels stay attached to their values and controls;
- targets retain at least 44 by 44 CSS pixels in these contracts;
- sticky regions leave the active control and content visible; and
- state and authority remain written.

Content whose meaning requires two dimensions—such as a matrix, map, technical
drawing, or data table—receives a local `role="region"`, useful label, visible
boundary, and keyboard-reachable scroll container. A semantic table or ordered
explanation supplies the same decision when visual navigation is impractical.

## Container ownership

Components respond to the inline size their owner provides. Container queries
may express component-local changes when the supported browser baseline and
fallback are recorded. Viewport queries continue to own page-level navigation,
print, and other environment changes.

Use logical properties so writing direction and inline flow remain explicit.
Min-content pressure is handled at the component that creates it: grid children
receive `min-inline-size: 0`; long identifiers wrap or receive a full-value route;
and the local inspection region carries irreducible geometry.

## Print record

Print presents the complete decision as a stable reading:

- light paper and dark text;
- visible section and state boundaries;
- captions beside their figures;
- tables with repeated headers when the browser supports them;
- open disclosure content that completes the record;
- source standing, evidence boundary, and receiving authority; and
- URLs or identifiers when the destination matters to the printed use.

Interactive controls may become written selected-state summaries. Navigation
and repeated interface chrome can recede while the working content remains.

## Review probe

1. **Question:** Which relationship requires two dimensions, and which content
   can reflow?
2. **Mechanism:** Inspect min-content contributors, grid and flex axes, fixed or
   sticky regions, long content, local scroll, and print fragmentation.
3. **Observable evidence:** The page fits 320 CSS pixels; local two-dimensional
   regions remain identifiable and operable; print preserves the full decision.
4. **Instruction yield:** Place overflow, wrapping, or fragmentation repair with
   the component that owns the geometry.

## Re-entry

A component width, content length, writing direction, target-size requirement,
sticky region, browser fragmentation behavior, or print requirement reopens the
fitting observation.
