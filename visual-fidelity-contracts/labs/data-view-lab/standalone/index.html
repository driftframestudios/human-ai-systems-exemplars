Relationship reading

Eleven named relationships connect the accepted workflow stages. Report release opens two routes: one for operations and one for follow-up.

  1. Intake → Triage: hands accepted intake to triage.
  2. Triage → Consent: routes a qualifying case to consent review.
  3. Consent → Accession: releases the consented case to accession.
  4. Accession → Extraction: hands accession state to extraction.
  5. Extraction → Sequencing: routes extracted material to sequencing.
  6. Sequencing → Analysis: routes sequence output to analysis.
  7. Analysis → Review: routes interpreted results to review.
  8. Review → Tumor board: prepares reviewed results for tumor board.
  9. Tumor board → Report: routes an accepted interpretation to reporting.
  10. Report → Billing: records report release for operations.
  11. Report → Follow-up: opens the follow-up route.

Reading and embedding boundary

This artifact is a static reading document built from synthetic public data. Its document policy permits inline presentation styling while keeping script execution, form submission, remote assets, network requests, and object embedding outside the reading route. A hosting owner supplies the response-level frame policy and an iframe sandbox that fit the receiving site.
