# Visual and data communication

## Current standing

This folder is a reader-entry route. The current repository-owned selector and
visitor projection live in the Visualization Fidelity Atlas family.

## Reader job

Use this route to choose a visual form by the data shape, cognitive job,
audience, interaction need, and production commitment it must support.

## Useful material

- [Visualization Fidelity Atlas prototype](../../../visualization-fidelity-atlas-bundle-v0.1/visualization-fidelity-atlas-chimeric-prototype-v0.1.html)
  and its [manifest](../../../visualization-fidelity-atlas-bundle-v0.1/visualization-fidelity-atlas-manifest-v0.1.json)
  lead to the schema, JSON-LD context, and local artifact closure.
- [Context Canvas Visualization Fidelity Atlas](../../../context-canvas-project-surface/context-canvas/visualization-fidelity-atlas.html)
  is the visitor-facing projection.
- [Focused prompt-capsule test](../../../tests/visualization-fidelity-atlas/atlas-prompt-capsule.test.mjs)
  protects the selected-state exchange behavior.

The Atlas supplies qualitative selection guidance and a synthetic exemplar.
It does not establish universal accessibility, comprehension, or quantitative
fidelity scores. Those claims require their own reader and task observations.
Driftframe Constellation retains wider package authority through
`urn:source-key:driftframe-constellation`.
