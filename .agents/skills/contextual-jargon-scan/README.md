# Contextual jargon scan

Use this skill to connect reader-facing wording to the concrete object, action, relationship, or consequence it carries. Exact terminology and useful compact language remain available.

## Start here

- Read the authoritative [skill contract](SKILL.md).
- Bind the corpus, intended readers, active change, exclusions, and candidate word families before searching.
- Treat search counts as candidate locations. Read every material occurrence in context and classify its function.
- Return targeted revisions, intentional retentions that affect future work, structural verification, and a receiver for any material deferral.

## Concrete example

**Situation:** A README introduces five starting points through a metaphor; direct names would make each concrete job easier to retrieve. The README later uses “API surface.” A frequency scan flags both word families.

**Use:** Classify the first phrase as replaceable shorthand because the reader needs concrete starting points. Revise the heading to “Five starting points connect questions to working systems.” Retain `API surface` because it names an established technical boundary; define it locally only if the intended reader needs help.

**Observable return:** The starting choices become directly retrievable, the technical term keeps its precise role, and a targeted rescan plus the README route check verifies the changed corpus. Reader legibility and focused verification define completion.

## Functional classes

1. Literal ordinary language
2. Exact technical or governed term
3. Quoted, cited, or source-owned language
4. Useful compact metaphor with a retrievable relationship
5. Replaceable shorthand that relies on local context

## Boundaries

Preserve source titles, quotations, code, schema keys, identifiers, product names, accessibility meaning, and source-owned terminology. Return a disputed governed term to its owner and preserve the governed form locally.
