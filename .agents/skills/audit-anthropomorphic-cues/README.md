# Audit anthropomorphic cues

Use this skill to inspect person-like interface cues as a bundle and make the acting system, useful relational value, evidence standing, and accountable human easy to distinguish.

## Start here

- Read the authoritative [skill contract](SKILL.md) before beginning an audit.
- Use it when names, pronouns, avatars, voice, emotional language, role metaphors, or agency claims may change reliance, delegation, responsibility, or recovery.
- Return a compact cue ledger and a proportionate `retain`, `qualify`, `separate`, `disclose`, `test`, or `revise` decision.

## Concrete example

**Situation:** An interface says an “AI collaborator decides which application to submit.” The observed workflow establishes that a generative system compares options and drafts a packet; a named person selects and approves the submission.

**Use:** Read the role label together with the interface name, turn-taking, permissions, and surrounding status cues. Separate proposal and drafting functions from selection, approval, and accountability.

**Observable return:** The cue ledger records the useful coordination value, the verified system behavior, and the human authority holder. Revised copy says that the system compares options and drafts the packet, while the named person chooses and approves the submission.

## Boundaries

Retain proper names, quotations, participant language, schema keys, route identifiers, and historical artifacts when they carry source or compatibility identity. An audit recommends the smallest useful change; a separately authorized evaluation establishes causal effects.
