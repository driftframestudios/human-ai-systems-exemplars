# ASCII zine composition

Use this method when a working interface or publication should feel like an
independent print artifact while its labels, controls, and state stay clear.
Read the [portable contract](SKILL.md) for the method and completion boundary.

For example, an investment studio can add a masthead, quiet ASCII grille, and
rose recovery slip around its existing controls. The visitor still chooses
people, previews a change, and applies it through ordinary semantic controls.
Removing the decoration leaves the complete task available.

The [ASCII Zine Field guide](../../../visual-fidelity-contracts/ascii-zine-field/index.html)
and [family source](../../../visual-fidelity-contracts/ascii-zine-field.md)
provide one concrete palette and vocabulary. This skill owns the transferable
composition method; the family owns those visual choices. The reviewed skill
selection prepares the contract for the next tagged Pages projection, while
the production manifest separately selects the guide and specimen.
