# Web data visualization

Integrate a chart, scientific figure, SVG gallery, or coordinated view into an
existing web page so its source, visible state, exact values, and portable
output agree. The page keeps a useful static reading while intentional
enhancement adds interaction.

## Start here

- [Read the authoritative skill contract](SKILL.md)
- [Return to the repository skills catalog](../README.md)

## Use it when

Use this skill when a web visualization's delivery mode, responsive behavior,
view state, table companion, or export affects interpretation. Use a lighter
conversation figure or PDF visualization route when the web page is not the
receiving artifact.

## What it returns

- one question-led figure or coordinated view family;
- source-owned derivation shared by marks, summaries, exact values, and exports;
- a static SVG or other useful baseline with a semantic companion;
- responsive and full-size access fitted to the actual container; and
- focused source, state, rendering, and interaction evidence.

## Concrete example

| Part | Example |
| --- | --- |
| Situation | A dense heatmap is readable on its full-size page but its labels collapse inside an iframe, and visitors need exact values for a selected cohort. |
| Use | Reuse the page's existing figure and table patterns, keep population filters separate from chart form, add local scrolling and a full-size route, and derive the table and export from the same accepted state. |
| Observable return | Labels remain readable in the embedded container, the selected cohort persists across compatible views, and heading, legend, marks, exact values, and export report the same denominator. |

## Working route

1. Locate the page, canonical data, renderer, styles, assets, table inventory, and existing checks.
2. Settle population, measure, comparison, absence, and uncertainty through the visualization foundation.
3. Reuse native HTML, static SVG, caption, table, and full-size patterns before adding dependencies.
4. Bind accepted state across controls, marks, summaries, exact values, and downloads.
5. Observe actual container width, keyboard and focus behavior, text visibility, and visual/table/export agreement.
6. Return the changed reader ability, evidence scope, and any separate publication decision.
