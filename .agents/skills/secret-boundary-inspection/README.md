# Secret boundary inspection

Prove the repository's secret detector with a fresh synthetic canary, then
inspect the exact material preparing to cross a handoff or publication
boundary. The resulting record stays useful without carrying candidate values
or raw scanner output into durable collaboration records.

## Start here

- [Read the authoritative skill contract](SKILL.md)
- [Return to the repository skills catalog](../README.md)

## Use it when

Use this skill before a snapshot, publication, delivery, or receiving-repository
handoff involving source, an exact proposed index, locally available history,
or a named artifact.

## What it returns

- a canary-proven detector path;
- separate results for every requested material scope;
- a concise safe receipt when all requested scopes are clear; or
- a private response route that pauses the affected handoff when a candidate appears.

## Concrete example

| Part | Example |
| --- | --- |
| Situation | A release candidate contains source files, Git history, images, and a generated archive. |
| Use | Prove the configured detector with a new canary, inspect the tree, exact index, available refs, and archive, then run a separate metadata observation for the images and archive. |
| Observable return | The handoff receives a zero-finding, scope-explicit receipt, or pauses with a named private owner; metadata coverage remains a distinct adjacent claim. |

## Working route

1. Bind the source coordinate, receiver, requested scopes, and repository-owned implementation.
2. Verify the pinned engine and reviewed configuration.
3. Generate a fresh provider-shaped canary and require detection plus redaction to succeed.
4. Observe each named scope without allowing one clean result to stand in for another.
5. Keep raw findings private; return only the allowlisted scope and outcome.
6. Ask the receiving repository to repeat the observation after assembly.

## Supporting material

This inspection establishes only the configured material scopes. Credential
validity, publication approval, rights, consent, and service-side exposure keep
their own owners and observations.
