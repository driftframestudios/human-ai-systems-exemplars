# Stateful artifact behavior contracts

Protect the smallest consequential journey through a stateful artifact. This
skill selects source-grounded checks for import, edit, rendering, export,
machine-readable agreement, and recovery while each artifact and schema keeps
its own meaning and ownership.

## Start here

- [Read the authoritative skill contract](SKILL.md)
- [Return to the repository skills catalog](../README.md)

## Use it when

Use this skill when state crosses forms, controls, reducers, adapters,
serialized documents, prompt projections, JSON-LD, successor records, or a
recovery path. A static page or isolated pure function usually has a smaller
direct test owner.

## What it returns

- one compatible journey and, when owned, one rejected path;
- the minimum usable state and stable identity rules;
- agreement among visible and machine-readable twins;
- detached exported state; and
- a recovery route that keeps accepted state usable.

## Concrete example

| Part | Example |
| --- | --- |
| Situation | A browser prototype exports an edited record, imports it into a fresh session, and also provides a JSON-LD projection. |
| Use | Put pure transformation checks at the unit layer and exercise export, import, focus, visible summary, JSON-LD agreement, and rejection through the focused browser harness. |
| Observable return | The edit and stable identity survive roundtrip, both representations agree on shared fields, later export mutation leaves working state unchanged, and an incompatible import preserves the accepted record with a revision message. |

## Working route

1. Map semantic owners, source state, schemas, transformations, twins, identity, and recovery.
2. Choose the smallest journey that could reveal a material defect.
3. Place each assertion with its owning unit, schema, browser family, or serialized boundary.
4. Distinguish a source defect from an absent protection before retaining a new expectation.
5. Exercise accepted state, roundtrip, minimum state, twin agreement, and recovery that the journey crosses.
6. Return the focused evidence and the boundary left for another owner.
