# Evidence-grounded research spike

Use current standards, official documentation, primary research, and named
practice to make one repository decision. Retrieval completes when added
examples leave the next action unchanged.

## Start here

- Read [`SKILL.md`](SKILL.md) for the authoritative evidence hierarchy,
  decision bridge, operating sequence, and completion boundary.
- Return to the [repository skill catalog](../README.md) to route the resulting
  implementation, writing, or source-authority work.

## What this skill returns

- the decision and repository artifact under review;
- material claims classified as verified fact, supported inference,
  practitioner observation, or open hypothesis;
- direct evidence routes and transfer limits;
- one counterexample or condition that tests the preferred route;
- the instruction, boundary, implementation, observation, or purposeful
  deferral that changes; and
- remaining uncertainty with a named receiver when it affects the next action.

## Concrete example

**Situation:** A team is deciding whether a browser capability can replace a
small JavaScript layout helper in a maintained component.

**Use:** Frame the exact component decision and support window, read the relevant
standard and current browser documentation, inspect one practiced implementation,
and challenge the route with the oldest supported runtime.

**Observable return:** The decision names supported engines and versions, the
fallback or progressive-enhancement rule, the local instruction that changes,
and the browser observation still needed for the maintained component.

## Working path

1. State the decision, receiving artifact, evidence-sensitive claims, and stop.
2. Retrieve evidence in descending authority.
3. Classify each material claim and its transfer boundary.
4. Test the selected route with a disconfirming condition.
5. Connect the research mechanism to a local design consequence and observation.
6. Return the evidence map, what the evidence changes, uncertainty, and direct citations.

This skill carries its complete working contract in [`SKILL.md`](SKILL.md).
Direct citations and their claim classes travel with each research return.
