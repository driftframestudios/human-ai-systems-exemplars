# First-use exercises for coordinated Atlas views

This is conditional task context for Issues
[#358](https://github.com/driftframestudios/human-ai-systems-exemplars/issues/358)
and [#360](https://github.com/driftframestudios/human-ai-systems-exemplars/issues/360).
The portable contracts remain the four `SKILL.md` files. Exercise descriptions
are prospective unless a receiving PR or Issue records the actual observation.
They are neither executable tests nor claims that a figure has already rendered.

different parts of a reading sequence while each panel keeps its own population,
measure, time basis, and source. Cross-panel numerical comparison requires those
definitions to agree.

## A. Conversation and source-contract exercise

**Receiving question:** Which distinction should the first coordinated view help
a visitor understand?

Apply the foundation and conversation skill to the admitted product-type counts.
Compare machine-failure label counts with their rates and with any-mode counts.
Consider an aligned comparison plus a 2-by-2 reconciliation matrix. Evaluate
whether a proposed stacked composition would imply exclusive membership that
the records do not supply. Return a selected view and its reason, not an expanded
dashboard merely to exercise every form.

**Observable result:** The selected reading keeps record counts, labels, and
memberships distinct; denominators and source standing remain available. Record
the decision-changing effect or lack of effect in the receiving PR. Source
arithmetic evidence from #365 remains distinct from rendered-view evidence.

## B. Coordinated web-view exercise

**Receiving question:** Can a visitor retain one product type while moving between
a count/rate comparison and label reconciliation?

Apply the web skill with existing Atlas styles. Build the smallest admitted static
baseline, native population/view controls, semantic table, text reading, full-size
route, and selected-state export that the actual implementation accepts. Preserve
the population and meaningful record identity across compatible changes. Use
existing state/render helpers where their ownership fits.

**Observable result:** Heading, unit, scale, SVG, exact-value companion, and export
agree on the selected state. Scriptless reading remains useful. Independent
fixtures and source review precede one focused affected-family browser campaign.
Renew changed cases after defects; existing observations retain their actual
scope. Skill use itself creates no site-wide test trigger.

## C. Heatmap and table-detail admission exercise

**Receiving question:** Does a speed-by-torque matrix reveal a pattern worth adding
to the compact comparison?

Before rendering, define fixed bins, endpoint rules, metric, unit, scale, and
denominators. Exercise exact boundaries, under/overflow, missing measurements,
empty cells, and populated zero-event cells as the contract requires. Decide
between event counts and rates explicitly; make sparse support visible if rates
are shown. Keep generated-data standing with the finding.

Compare a native adjacent detail table with the proposed nested-table option.
Choose the simpler fit unless a genuine subordinate relationship earns nesting.
If nested, the existing projector and native-header contract receive a bounded
admission check before publication. Local scrolling and full-size access preserve
labels rather than squeezing the matrix to the embed width.

**Observable result:** A meaningful view earns inclusion, or the candidate rests
with a specific reason. The existing table inventory and projection remain the
admission owners; the skills introduce no parallel table registry.

## D. Portable scientific/PDF exercise, when requested

**Receiving question:** Does the selected comparison remain legible as a
single-column figure or report panel?

Activate the PDF skill only when a PDF receiver is real. Reuse the admitted values
and plotting pipeline, declare physical dimensions and uncertainty, and observe
the final placed output. Compare labels, source context, and exact values across
the web and PDF carriers. Record font, raster/vector, or placement findings only
when they change the result.

**Observable result:** The document receiver can read and recover the figure at
final size. The current web wave can leave this exercise at rest without losing
its source or later re-entry condition.

## E. Separate research-extract gate

**Receiving question:** Which topics have broad source coverage and which have
documented application within an approved public extract?

Apply the portable [public-extract and search-coverage admission](form-and-data-contract.md#public-extract-and-search-coverage-admission)

repository and asset pipeline; the public citation boundary includes the

candidate once the extract's topic coverage and documented-application meanings

**Observable result:** An approved extract yields a bounded visual contract and
citations, or the gate stays open with the smallest missing authority/data input.
The admitted manufacturing data can continue independently.

## Cultivation and release

Use the existing receiving Issue or PR as the observation owner. Preserve only
the reader job, skill/reference used, decision changed, observable outcome,
material friction, coverage boundary, and disposition. Useful dispositions are
retain, refine, fold into an existing owner, rest, or retire. A successful authored
scenario establishes a local exercise; rendered use and cross-context transfer
earn their own evidence. Repetition count alone supplies no effectiveness claim.

A fresh-context exercise can also test a near miss, direct-reasoning case, and
public-only use. Keep expected results independent from the evaluator's prompt
when assessing routing behavior. The next real Atlas wave supplies the primary
material-use observation; further review rests when it leaves that next decision
unchanged.

These source drafts prepare a future public skill offering. The complete method
and dependency/reference closure must travel in its selected package. Hosted
publication remains held until a new tag and complete public carrier are produced.
