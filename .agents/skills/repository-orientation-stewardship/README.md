# Repository orientation stewardship

Help a first-time or returning contributor find what the repository enables,
where current truth lives, and what to inspect or run next. This skill improves
the README graph while runnable source, manifests, releases, and live work keep
their existing authority.

## Start here

- [Read the authoritative skill contract](SKILL.md)
- [Return to the repository skills catalog](../README.md)

## Use it when

Use this skill when a root README and its nested READMEs repeat mutable status,
hide the quickest useful example, or disagree about which source owns a claim.
A single wording correction or broken link can proceed through direct editing.

## What it returns

- a layered route for a first visit, repeat use, and re-entry;
- intent-based links to source owners and useful proof;
- clear standing for snapshots, generated copies, and maintained sources; and
- focused evidence for the README routes that changed.

## Concrete example

| Part | Example |
| --- | --- |
| Situation | A root README lists every directory before explaining what can be used today, while a nested README repeats an outdated release coordinate. |
| Use | Identify reader jobs, trace the release claim to its manifest, lead with practical starting points, and link the nested README back to its owner. |
| Observable return | A cold reader can reach the current example, source authority, verification command, and return path while the named manifest or source continues to govern release truth. |

## Working route

1. Confirm the branch, worktree, current collaboration record, and nearest instructions.
2. Name the reader jobs and distinguish a first visit from repeat use and re-entry.
3. Map mutable claims to their source, manifest, release record, or live receiver.
4. Repair the smallest useful set of root, family, and owner routes.
5. Exercise changed links, fragments, and repository-specific documentation checks.
6. Return the changed routes, what the checks establish, and the exact next entry point.

The skill rests when practical value, current truth, authority, evidence, and a
return route are reachable in one coherent traversal.
