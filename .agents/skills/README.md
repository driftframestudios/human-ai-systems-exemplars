# Repository skills

Repository skills make recurring collaboration methods available on demand.
Each `SKILL.md` is a portable working contract rather than a claim of truth,
priority, permission, or competence. Current user intent, repository evidence,
and granted tool authority govern every activation. Direct reasoning remains
the smallest adequate route when no contract adds material value.

## How the catalog evolves

`collaboration-accounting` routes natural
use, human correction, and independent evidence into formation, revision,
observation, settlement, consolidation, or retirement. The
[`collaboration accounts`](../../threadkeeping/collaboration-accounts/README.md)
preserve decision-changing field evidence. Git history carries contract
evolution; GitHub Issues retain current outcomes and acceptance.

[`AGENTS.md`](../../AGENTS.md) supplies standing repository ground, while
[`runbooks`](../runbooks/README.md) carry known multi-phase procedures. A skill
owns one reusable result; a runbook sequences existing owners for one known
route.
