# Repository skills

Choose a recurring method by the result the work needs. Each skill overview
starts with its everyday use and a concrete example; its `SKILL.md` carries the
authoritative contract, boundaries, operating sequence, and completion state.

Current user intent and granted tool authority govern each action; repository
evidence governs factual claims. A skill contributes a reusable method within
those authorities. Direct reasoning is the fitting route when one local action
completes the job.

## Start with the reader job

1. Choose the result that most directly serves the current task.
2. Read the skill overview to confirm fit through its concrete example.
3. Read the linked contract completely before using the method.
4. Load only the scripts or references that the contract routes for the active branch.
5. Return one receiving result with its evidence boundary and next action.

### Concrete example

| Situation | Selection | Observable return |
| --- | --- | --- |
| A contributor resumes a repository after several merged pull requests and needs the current source, open decision, and next action. | Begin with the `repository-reentry` overview in the catalog below, then follow its authority route into the contract. | A concise current-state model names the behavior source, live collaboration record, an outdated collaboration record if one exists, and one bounded continuation. |

## How the catalog evolves

The `collaboration-accounting` overview and contract route natural use, human
correction, and independent evidence into formation, revision,
observation, settlement, consolidation, or retirement. The
[`collaboration accounts`](../../threadkeeping/collaboration-accounts/README.md)
preserve decision-changing field evidence. Git history carries contract
evolution; GitHub Issues retain current outcomes and acceptance.

[`AGENTS.md`](../../AGENTS.md) supplies standing repository ground, while
[`runbooks`](../runbooks/README.md) carry known multi-phase procedures. A skill
owns one reusable result; a runbook sequences existing owners for one known
route.
