Use `node:test` for Strategy Canvas core and the Narrative Capsule Strategy v2
adapter. Use Ajv for the adjacent governed instances. Reuse Playwright for page
behavior that requires a browser. The existing dependency set carries the first
baseline.

Standard runner output carries the first baseline. The Actions receiver calls
the same commands and rests automatically when its repository variable is
unset or `false`. A general assessment schema, profile registry, or second
receipt format returns after material use demonstrates a shared job.

### Artifact-owned meaning

Schemas, examples, adapters, manifests, and meaning-bearing fixtures remain
beside the artifact that owns them. A central `tests/` route may carry the
executable assertions and a concise ownership map. Source, semantic,
implementation, and publication authority remain distinct.

### Independent expectations

An accepted behavior case names the source, affected actor, consequence,
input/action, observable result, recovery behavior, fitting test layer, and
review authority. AI-generated tests remain candidates. The first baseline is
grounded in current source defects and human/source-owned expectations.
