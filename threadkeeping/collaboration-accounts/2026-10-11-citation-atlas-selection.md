## Working observation

A 648-record public citation Atlas supplied useful exact identities, public
routes, lifecycle state, reader jobs, and selection boundaries. Committing the
complete discovery corpus would have added historical observations and
instruction-shaped source prose to a repository that needed only a reviewed
route selection. Manual search also made exact-title collisions, alias records,
and current-versus-archived state easy to overlook.

The exercised helper kept the Atlas external and inert, accepted an explicit
local file, bound each result to the input byte count and SHA-256 digest, and
emitted an allowlisted projection. An exact-key lookup resolved
the durable coordinate for a selected Registry page. A filtered search returned
the intended PODA investment page with visible score components. A bounded list
confirmed stable ordering within one family and resource role. The resulting
binding carries 77 exact current records; a separate discovery pass added eight
fitting links to seven visitor pages and one catalog without changing the About
page.

## Disposition

`citation-atlas-selection` receives `create_now`. Its result differs from nearby
owners:

- `source-authority-mapping` determines which source owns a claim or field;
- `locator-boundary-stewardship` decides which locators may cross a publication
  boundary;
- the public-reference materializer replaces already reviewed semantic tokens;
  and
- `citation-atlas-selection` discovers and compares exact Atlas records before a
  receiver chooses one.

The skill and dependency-free `lookup.py` remain portable. They contain no
repository name, operator identity, caller filesystem path in failure output,
private locator, implicit Atlas location, network retrieval, publication
mutation, or platform-specific action authority.
The first exercise earns repository use. Public projection remains
`public_possible` until an independent receiving use and a complete source-package
review test the helper against another legitimate Atlas shape.

## Evidence boundary

The first use establishes deterministic parsing, filtering, ranking, and exact
selection against one accepted Atlas snapshot. Twenty-two behavior tests cover
strict JSON, UTF-8, size bounds, public-route admission, lifecycle filtering,
token-boundary search, ambiguity, stable output, and machine-readable failures.
This evidence supports the present source shape;
it does not establish universal ranking quality or citation fitness. The
receiving claim and the selected public source still determine whether a link
belongs.

## Re-entry

Return when another team supplies a different public-safe Atlas, when a current
record changes identity or lifecycle, or when a receiving page exposes a field
the allowlisted projection genuinely needs. Smooth exact-key reuse can remain
ordinary work.
