# Collaboration accounts

Collaboration accounts preserve situated observations from materially meaningful repository work. Each account names the working moment, the affordance a skill supplied, the friction or limit that appeared, and the consequence for a later collaboration cycle.

These notes remain provisional field evidence. Repeated use can earn a skill revision, a new example, or a clearer trigger; a single smooth use can remain simply useful. The account records consequential moments rather than reconstructing every turn, measuring collaborator performance, or establishing a permanent skill ranking.

## Return condition

Add or extend an account when active work changes a repository decision, reveals a repeatable skill affordance, exposes friction that would alter the next use, or tests an earlier observation in a new terrain. The owning `SKILL.md` changes when the accumulated evidence identifies a narrow revision that would improve another real collaboration cycle.
