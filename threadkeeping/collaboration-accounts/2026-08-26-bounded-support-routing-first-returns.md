## Skill return

`bounded-support-routing` remains a useful portable affordance. The practiced
returns support a `retain` recommendation and the `settle_or_fold` route through
four narrow conditions:

- a formed stop condition suspends every unconsumed action in the current grant;
- evidence that disproves a requested-result premise returns a
  `repair_authorized` or `implementation_authorized` packet to Solution before
  further mutation;
- the named handback surface receives a concise pass, friction, or blocker even
  when a branch, diff, or pull request preserves useful work; and
- GitHub labels expose packet type, selected Codex projection, and whether a
  return is awaited or posted, while the named Issue surface and receipt carry the
  operative grant and evidence.

The exact repository coordinate, focal file, action mode, granted actions,
focused observations, and known-good point all materially supported re-entry and
recovery. They remain in the packet.
