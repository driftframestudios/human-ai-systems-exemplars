    Source Note
    
    
    This artifact inherits the test-first / TDD rhythm and adapts it into Business Rule Protection: vital behaviors and deal-breakers become platform-agnostic test targets before redesign, refactor, or AI-assisted implementation changes the surrounding system.
    
    
    Source anchors include Agile Alliance’s TDD glossary, which describes TDD as tightly interweaving coding, unit testing, and design/refactoring through a cycle of writing a single unit test, running it and seeing it fail, writing just enough code to pass, refactoring, and repeating while accumulating tests. Kent Beck’s Test Driven Development: By Example remains a key source reference for the inherited lineage.
    
    
    Local Core Architecture adaptation: this prototype focuses on protected behavior boundaries, intentionally unprotected areas with rationale, implementation evidence, and routing test evidence into adjacent artifacts. It is not a complete testing program.
