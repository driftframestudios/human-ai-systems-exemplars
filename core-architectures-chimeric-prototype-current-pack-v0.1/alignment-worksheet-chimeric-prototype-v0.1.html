Alignment Worksheet

Forward / Backward Premise Surface. A six-blank premise worksheet with option spreads, probability-of-what discipline, and inverse-state recovery reasoning.

Placement: Solution Architecture · Recovery Routing participant Family: Orientation and Tracing / Comparison and Threshold Primary move: premise alignment and temporal backcasting

Quick Use

Use this when

A team needs to align who is affected, what they want, what current path they use, why that path asks for change, what restored state is imagined, and which broad approach may help.

This restores

Premise coherence across present state, desired state, and broad approach.

Preferred phrasing

          
    
            
  • What world is this worksheet describing?
    • 
            
  • Which blank carries the most uncertainty?
    • 
            
  • What is the probability of what?
    • 
            
  • Which Core Architecture can make this premise more inspectable?
    • 
          

        

        

          
Replacement-state guidance

          
    
            
  • Use “The current path asks for change because…” instead of sharper source-language phrasing.
    • 
            
  • Use “broad approach” before the exact implementation path is known.
    • 
            
  • Use “inverse-state pass” rather than failure-state language for everyday operation.
    • 
          

        

        

          
Recovery cues

          
    
            
  • Participants argue over the first few premise blanks.
    • 
            
  • AI options sound plausible but rest on different assumptions.
    • 
            
  • The broad approach appears before the restored state is clear.

Source Note

      
This prototype preserves the local Alignment Worksheet name and six-blank premise surface. Exact external worksheet lineage can remain in human-maintained provenance notes; the active artifact uses calm replacement-state language and avoids sharper source-team naming in AI prompt capsules or generated diagram labels.

      
The local adaptation adds AI option spreads with probability-of-what, inverse-state recovery, stable IDs, JSON/JSON-LD, and AI collaboration context.
