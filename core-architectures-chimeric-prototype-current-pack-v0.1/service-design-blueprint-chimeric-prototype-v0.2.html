Service-design Blueprint

Service Topology Map

A layered service map that shows visible experience, backstage work, AI or agent participation, system behavior, data and evidence, governance surfaces, and handoffs across a service journey. The HTML table is the reading and editing surface; the SVG is a compact visual companion generated from the same stable IDs.

Quick Use

Use this when

A team needs to see how visible experience, backstage work, AI or agent behavior, systems, data stores, policies, evidence, and handoffs fit together across a service journey.

This restores

Layered service visibility.

Good next question

Service Blueprint Setup

Service stages

Stages are semantic sequence columns. For v0.2 they can be hidden for focus, but not reordered casually.

Service layers

Layers are a semantic stack. Hide/display is focus state, not deletion or redaction.

Text / Table Equivalent

Select a cell to reveal and edit the full text, routes, linked shared assets, and stable IDs. Long text remains preserved in the data model even when previewed compactly.
