Context Tree

Role–Knowledge Context Map with stable semantic identity, active view state, column ordering, and focus-view visibility controls.

Placement: Solution Architecture Family: Orientation and Tracing Move: role/context/knowledge-gap mapping Status: prototype v0.1.3

Quick Use

Use this when

A team has named actors, groups, roles, or teams, and now needs to understand their working context: who they collaborate with, what they need to know, and what context still needs to surface.

This restores

Role-specific context locality.

A good next question

What does this group need to know to act responsibly, confidently, and in coordination with others?

AI collaboration capsule: preserve role-specific context, translate “what are they missing?” into “what context still needs to surface?”, keep status markers visible, treat hidden columns as a focus view rather than deletion, and route context cells into the smallest adequate next Core Architecture.

Editable Role–Knowledge Matrix

The matrix below is the source of truth. The SVG diagram, table equivalent, JSON export, JSON-LD, and AI prompt are generated from the same stable row, group, and cell IDs. Column order and visibility are active view state.

Focus View Controls

Hide/display and order affect presentation only. Stable group, row, and cell identities remain unchanged in JSON, JSON-LD, and source data. Hidden columns are not redacted.

      Semantic Locality and Recovery

      Preferred phrasing

      • What does this group need to know to act responsibly?
      • Who does this group work with, depend on, or hand off to?
      • What context should become visible for this group?
      • Which context item should become a discoverable?

      Recovery calibration

      • Strain cue: role differences are being flattened.
      • Stabilizing read: the collaboration needs role-specific context locality.
      • Restored state: groups, collaborators, knowledge needs, and context still to surface are visible.
