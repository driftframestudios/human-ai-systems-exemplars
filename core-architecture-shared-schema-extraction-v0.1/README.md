# Core Architecture shared schema extraction v0.1

This directory retains an illustrative extraction of a Core Architecture
artifact family. It shows how a compact envelope, JSON-LD context, registry,
repository-structure sketch, and explanatory reading can travel together as a
source-local reference.

## Contents

- `core-architecture-envelope.schema.v0.1.json` describes the illustrative
  artifact envelope.
- `core-architecture.context.v0.1.jsonld` carries the extraction's local terms.
- `core-architecture-artifact-model-registry-v0.1.json` presents example model
  relationships.
- `core-architecture-repository-structure-sketch-v0.1.md` explores a receiving
  repository shape.
- `core-architecture-shared-schema-envelope-extraction-v0.1.md` explains the
  source reading and its boundaries.

Existing files and routes remain available for collaborators examining this
earlier Core Architecture model or tracing pages and prototypes that discuss
the family.

## Context Canvas relationship

Context Canvas collections, visitor surfaces, prototypes, and reference
artifacts take their current governing contract from
[`schemas/context-canvas/1.0.0/`](../schemas/context-canvas/1.0.0/README.md).
The exact schema identity is
`https://schemas.vik.guru/context-canvas/1.0.0/context-canvas.schema.json`; the
GitHub-backed retrieval mirror is
`https://schemas.radiantnull.com/context-canvas/1.0.0/context-canvas.schema.json`.

The Context Canvas contract carries designed experience, standing, divided
authority, representations, relations, fidelity references, and recovery
routes. This extraction remains a useful Core Architecture exemplar with its
own vocabulary and evidence posture.

## Authority and extension

Human-readable source and the nearest package or surface documentation govern
interpretation. Schemas constrain their declared exchange shapes, contexts
expand their declared terms, and namespaced extensions preserve local meaning
when a shared core would flatten it.
