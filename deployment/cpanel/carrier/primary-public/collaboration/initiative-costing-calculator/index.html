08 · Adjust change attention

Change allocation

Redistribute relative attention across a separate, analytic eight-part change lens. The three highest-weighted components are emphasized in the Coordination Horizon’s Change work row; when Dual operating system is selected, all eight appear concurrently. The weights express relative attention; source-specific model structure, local evidence, and accountable judgment determine fit and observed adoption.

Artifact-native method: eight adjustable weights expose where coordination effort receives attention. The distribution works as a question-forming view: broad participation remains a staffed consideration, evidence standing stays visible, and local observation determines a useful allocation.

09A · Read the changed work

What this investment changes

Four Actions planning lens

Read the active change model through Raise, Reduce, Eliminate, and Create. The model’s own component nouns stay visible; Now, Next, and Later indicate a planning sequence, not a universal maturity path.

Kotter’s 8 Steps is active. These prompts reframe planning attention without merging or ranking the underlying model.

Raise Now

Create urgency. Raise attention to the initiating condition and the evidence a named owner will use to judge it.

Reduce Next

Build coalition. Reduce ambiguity about who participates, who decides, and which handoffs require review.

Eliminate Now

Enable action. Eliminate silent scope by marking the component planned, partial, Look here, or intentionally outside.

Create Later

Anchor change. Create a staffed evidence route with a named human receiver and an explicit re-entry condition.

This is a question-forming planning treatment. The named initiative owner retains authority for purpose, sequencing, scope, staffing, quality, and exceptions.

Method source and local adaptation. The Four Actions Framework was developed by W. Chan Kim and Renée Mauborgne to ask what to eliminate, reduce, raise, and create when shaping a new value curve. Read the authors’ framework description (opens in a new tab). This action area uses the four categories to organize editable planning suggestions. Market-strategy conclusions retain their own evidence and review.
