09A · Read the changed work

What this investment changes

Four Actions planning lens

Read the active change model through Raise, Reduce, Eliminate, and Create. The model’s own component nouns stay visible; Now, Next, and Later support discussion of this initiative’s sequence.

Kotter’s 8 Steps is active. These prompts organize planning attention using the active model’s own components.

Raise Now

Create urgency. Raise attention to the initiating condition and the evidence a named owner will use to judge it.

Reduce Next

Build coalition. Reduce ambiguity about who participates, who decides, and which handoffs require review.

Eliminate Now

Enable action. Make component scope explicit: planned, partial, Look here, or intentionally outside.

Create Later

Anchor change. Create a staffed evidence route with a named human receiver and an explicit re-entry condition.

This is a question-forming planning treatment. The named initiative owner retains authority for purpose, sequencing, scope, staffing, quality, and exceptions.

Method source and local adaptation. The Four Actions Framework was developed by W. Chan Kim and Renée Mauborgne to ask what to eliminate, reduce, raise, and create when shaping a new value curve. Read the authors’ framework description. This action area uses the four categories to organize editable planning suggestions. Market-strategy conclusions retain their own evidence and review.
