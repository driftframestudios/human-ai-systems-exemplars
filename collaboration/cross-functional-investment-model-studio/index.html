Activity-Based Throughput and unit economics; a project total hides the activity consuming resources. Name driver events; separate fixed and variable costs; trace costs to denominators; recompute at current and target volume. Driver counts, approved cost lines, volumes, rates → driver register, unit costs, scale sensitivity, reserved-input list. Approved denominators and local cost lines establish the reading. Reserved economics remain reserved. Choose drivers, authorize allocation, interpret operating consequences. Draft taxonomy, reconcile terms, surface missing denominators. Allocate costs, divide by events, recompute scenarios. Driver spreadsheet or data model plus repeatable calculation script. Draft a driver register; name numerator, denominator, source, owner, and missing input; assign no economics.
Benefit Realization / ROI The decision needs an explicit counterfactual, benefit mechanism, and value horizon. Price current burden; attach a mechanism to each benefit; phase realization; apply approved discounting; compare with status quo. Burden register, benefit inputs, committed cost, ramp, discount rate → baseline, benefit schedule, payback, NPV/IRR, reserved-value register. Each benefit carries a mechanism and approved input. Unquantified value remains reserved; negative value remains usable. Authorize counterfactual, mechanism plausibility, horizon, and threshold. Map mechanisms, surface double counting, draft next-learning questions. Phase and discount cash flows; calculate payback, NPV, and IRR. Value ledger joined to a deterministic financial model. Build a benefit-mechanism register before calculation; preserve unavailable value as reserved.
Bottom-Up WBS An auditable estimate must survive package-by-package review. Decompose owned packages; attach roles; add approved hours and rates; roll up hours × rate; separate contingency. Packages, roles, hours, rates, exclusions → resource-loaded WBS, base estimate, role demand, assumption register. Every dollar resolves to owned work and approved inputs or an explicit reserved field. Reserve stays separate. Define packages, roles, hours, rates, dependencies, and exclusions. Draft package tree, challenge missing work, normalize names. Multiply hours by rates; roll up and reconcile totals. WBS table or project-cost database with stable package IDs. Draft packages with IDs, owners, acceptance, dependencies, and reserved hour/rate inputs.
Executive One-Pager A sponsor needs a decision-grade leave-behind after source models establish the case. State the decision; name current burden; pull recommendation and headline commitment; carry value, risks, milestones, and sources. Ask, sourced figures, value case, risks, recommendation → one-page brief, headline commitment, recommendation, synopsis. The one-pager aggregates and originates no figures. Pause or decline remains an executive-grade recommendation. Own ask, recommendation, material risks, and decision timing. Compress supplied models, check consistency, draft scan-friendly alternatives. Pull approved values, verify source IDs, reconcile and render. Traceable publishing template fed by approved model fields. Draft ask, burden, recommendation, one sourced commitment, value, risks, and timeline; originate no numbers.
Probabilistic P50/P80 A point estimate obscures material range and the initiative needs explicit percentile postures. Use WBS IDs; replace points with approved three-point ranges; assign distributions; simulate; carry P80 − P50 as reserve. WBS, ranges, distributions, dependencies, run settings → distribution, P50/P80, reserve, S-curve data, tail drivers. Percentiles describe the modeled distribution rather than delivery certainty, approval, or realized spend. Authorize ranges, distributions, dependencies, commitment posture, and tail response. Draft elicitation questions, surface coupling and missing cases, explain structure. Sample, aggregate trials, calculate percentiles, rank tail contribution. Versioned simulation script or established cost-risk tool with reproducible settings. Request three-point ranges, source, owner, rationale, and dependencies; assign no ranges.
Risk-Register Contingency A flat contingency percentage cannot explain reserve or mitigation priority. Use lived failures; assign owner, mitigation, probability input, and impact range; reconcile reserve; rank sensitivity. Failure register, owners, probability/impact, mitigations → owned register, reserve, rollup, sensitivity, priorities. Named, locally reviewed risks form the reserve. Realized failures remain visible beside prospective risks. Name and own risks; authorize inputs, mitigations, and escalation. Retrieve failure evidence, draft risk statements, challenge missing routes. Compute probability × impact; aggregate, reconcile, and sort sensitivity. Risk database with stable IDs plus deterministic rollup and sensitivity script. Draft risks with trigger, object, consequence, owner, mitigation, recovery, placeholders, source, and status.
Three-Branch TCO Leadership is choosing among buy, build, and blend on a like-for-like basis. Fix common baseline; define branches; use one horizon and row set; separate one-time/recurring; name non-cost factors. Baseline, definitions, costs, horizon, factors → branch table, TCO, difference drivers, posture, recommendation. Every branch shares baseline, horizon, and category grammar. A branch can lose cleanly on a material constraint. Define branches, judge non-cost factors, authorize recommendation and exits. Normalize rows, find asymmetric assumptions, draft evidence-based trade-offs. Sum identical rows; separate cost types; calculate deltas. Branch-comparison table enforcing identical categories and horizon. Frame buy, build, and blend with common rows, sources, owners, and missing inputs; assign no prices.
Whole-Life TCO The decision includes recurring operation, scaling, parallel run, revalidation, and retirement. Select horizon; separate one-time/recurring; add run lines; cost double-running and retirement; model scale; discount. Implementation, recurring lines, retirement, scale path, discount/FX → annual table, CapEx/OpEx, scale, lifecycle value. Every approved year, run line, scaling assumption, and retirement obligation remains explicit and owned. Choose horizon and scaling; authorize run, FX, discount, operational, and retirement assumptions. Surface forgotten lifecycle lines, draft questions, compare source coverage. Roll annual costs; apply escalation and discounting; calculate lifecycle totals. Year-indexed lifecycle ledger plus deterministic finance formulas. Create year-indexed rows with source, owner, start/end, escalation, discount, FX, and reserved inputs.
