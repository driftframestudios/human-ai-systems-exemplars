02 · Nine stable capability contracts

A capability hierarchy for durable laboratory meaning

Stable identifiers keep scientific truth, platform fit, reversible operation, and accountable effect aligned across implementations, simulations, scenarios, and acceptance decisions.

  1. SPEC-LIFE-001

    Attributable specimen lifecycle

    Scientists see one current state while the complete decision record remains reconstructable.

    Shared scientific truth
  2. SPEC-CUST-001

    Versioned custody transfer

    Laboratory operations can locate a specimen and resolve concurrent movement safely.

    Shared scientific truth
  3. SPEC-INST-001

    Raw-artifact-preserving instrument ingress

    A scientific reviewer can connect a reported observation to the exact received bytes.

    Shared scientific truth
  4. SPEC-VEND-001

    Configured vendor conformance

    Evaluators can distinguish configured platform compatibility from adapter plausibility.

    Platform conformance
  5. SPEC-MIGR-001

    Meaning-preserving migration and recovery

    Records move and recover while identity, meaning, lineage, signatures, and artifacts remain intact.

    Reversible operation
  6. SPEC-SECO-001

    Tenant security and observable operation

    Owners operate with attributable access, protected telemetry, and measurable recovery.

    Reversible operation
  7. SPEC-SECR-001

    Workload-bound configuration and secret lifecycle

    Operators rotate credentials and change non-secret configuration through governed runtime stores while evidence surfaces retain references or redacted metadata.

    Reversible operation
  8. SPEC-ACPT-001

    Accountable multidomain acceptance

    Scientific, Quality, and Regulatory decisions remain distinct, bounded, and reviewable.

    Accountable effect
  9. SPEC-CALL-001

    Bounded tool-operation caller

    A person, service, workflow, or bounded generative AI tool caller selects a released operation while the service establishes identity, authority, scope, effect, evidence, and recovery.

    Accountable effect
