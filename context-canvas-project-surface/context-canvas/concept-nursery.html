Concept Nursery — Shared Staging for Pages Being Grown

A stable place for work that must exist before its final home is known

The Nursery is a shared bench across collaborators. It gives an unsettled page enough identity, placement intent, and status to be found and continued without forcing a taxonomy before the concept has settled.

Stage the page with a named destination; move it when its use settles; record the move so the next collaborator does not search twice.

Lifecycle — create, grow, settle, place

The lifecycle is directional but revisable. Intended home can change while a concept grows; the current destination and platform remain visible so another collaborator can continue from the same placement hypothesis.

02 · Shared Surface Priority Map companion

See what is shared before optimizing what is most visible

The Nursery gives an unsettled page a recoverable place. The paired Shared Surface Priority Map helps a visitor decide which shared object deserves to be grown first. Build a stages × surfaces matrix, mark coordination intensity with text and pattern as well as color, draw a hard line beneath the visible experience, and connect each stage to the shared assets, definitions, rules, and evidence it depends on.

Debrief

Map stages, surfaces, intensity, and shared assets

A heatmap shows where coordination pressure concentrates; a hard line keeps shared definitions, evidence, rules, and services visible beneath the experience surfaces they support.

The Snag

Separate surfaces quietly depend on the same assets

Teams optimize their visible channel while shared identities, definitions, services, data, and handoffs remain unowned or duplicated.

The Read

Shared topology precedes local optimization

The team needs to see which surface crosses the most stages and populations, and which hidden assets make several experiences possible.

The Move

Build the matrix and connect below the line

Name stages and surfaces, define an intensity basis, mark each cell accessibly, then link visible work to the shared assets it consumes or changes.

The Cure

Investment follows coordination unlocked

Local improvements can be calibrated against cross-surface effects, and a shared object earns priority by the work it makes possible across groups.

The Guidance

Ask which shared object removes the most reconciliation work

Choose the first surface by dependent stages, affected populations, and reusable assets—not by visual prominence alone.

Sample the shared-object candidates before naming the winner

Prompt-Side Conditions identifies diet blindness: the answer can only forage among the material the context makes available (Ragavan and Alipour, 2024 — information foraging in LLM chat). Give an AI collaborator the stages, populations, current artifacts, sources, omissions, and disclosure boundaries as a selected working set. Supply the selected topology directly so quieter systems and populations remain visible alongside the loudest channel.

Verbalized Sampling can produce several candidate shared objects, each with the coordination it may unlock, its key assumption, a falsifier, and the population it foregrounds. Compare that candidate set before choosing the first object to grow (Zhang et al., 2025 — Verbalized Sampling).

Inspect the paired Shared Surface Priority Map

The prototype makes the matrix, hard line, multi-population reach, and prioritization consequence inspectable after the method and its limits are established. Use it as-is to choose a first shared object; invert sparse or disputed cells into a research plan; adapt stages and surfaces to an industry; extend shared assets with organization-owned definitions; connect the selected object to the Nursery and its artifact pipeline; or let an AI collaborator maintain candidate links inside a human-governed review loop.

03 · Temporary context substrate

A temporary, headless wiki posture carries context without pretending the model remembers

The related Registry reading describes the knowledge substrate as closer to a temporary, headless, configurable wiki—with associated skills, bounded collaborator workflows, and diagram specifications—than a platform installation. The AI collaborator is a temporary context holder. Small, flat, self-contained, versioned files carry the identity, contract, source lineage, and boundaries that must survive when the collaborator does not.

Operator-blind substrate

Describe the work independently of today’s harness

“Operator-blind” means tool- and harness-independent: another compatible collaborator can read the same source-native object. It never means blind to human authority, affected populations, or operating consequence.

Temporary context

Reload a selected working set

The system assumes session continuity may fail. The Nursery link, status, sources, intended home, and Shared Surface map provide a bounded packet that can be deliberately reintroduced.

Human settlement

Let AI propose; let accountable people place

An AI collaborator may identify duplicates, propose a destination, or draft a map. A steward or receiving population decides when material is settled, moved, disclosed, superseded, or removed.

Evidence return

Version the correction, not only the output

Each review can return a revised expectation, corrected focus, source boundary, or resolved indeterminacy into the shared object for the next pass.

Memory boundary

This posture is not autonomous long-term memory, a new source of truth, an archive, a secret store, or permission to ingest everything. Only material appropriate to the declared disclosure and retention conditions enters the working set. Authoritative records remain authoritative; access, consent, privacy, security, deletion, and domain review stay with their accountable systems and people. The wiki is temporary and reconstructable by design.

Register — current source snapshot

The governing source currently contains no registered pages. The empty state is material: it preserves the instrument’s actual standing without inventing examples that could be mistaken for active work.

Changed work — unplaced work stays findable and continuable

Investment and stewardship

At creation

Name enough to continue

Supply a clear title, intended home, authoring platform, and current status. The Nursery asks for placement information, not a fully resolved taxonomy.

While growing

Keep receiving context current

Update intended home when the concept’s use changes. Review the content and placement hypothesis together.

At movement

Leave a route, not a ghost

Move the page, update status, and record the receiving location in the same collaboration cycle.

The four visible status labels are presentation cues rather than a closed source enumeration. Boundary-object research supports coordination without full consensus, but it does not supply this prioritization method; no study tests whether the map selects the best first object, machine-readable stable-core claims remain an inference, and the supporting research is largely retrospective.
