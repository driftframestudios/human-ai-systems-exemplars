Prompt-Side Conditions: A Practice Guide for Collaboration Teams

Shape the source, option space, and decision route before generation begins.

A short request can quietly ask a model to infer the educator, audience, evidence, and review route. This guide helps a team make those collaboration conditions inspectable. Begin with one consequential human reference, then test-drive the Open Lesson Field as it builds a working prompt capsule. The deeper method follows the lab, where each choice can be connected to source standing, uncertainty, option space, and a named human receiver.

Test-drive orientation · consequential task position

I. Resolve the human reference when it can change the work

Conversation can remain natural. When a reference could change role, authority, audience, evidence, ownership, or personalization, give the packet an explicit anchor: the classroom educator, curriculum lead, receiving team, or another named function. The pronoun itself is ordinary collaboration language; task position is the condition to inspect.

Look here · speaker role remains open

Speaker-relative request

“Make me a lesson plan for high-school Math students.”

“Me” denotes the speaker, while the speaker’s task role remains unstated: educator, learner, author, approver, or intended receiver. The collaboration still needs that task position; the AI collaborator can ask, and the requester can name which speaker-specific context should shape the artifact.

Surface cue changed · task position still open

Surface cue changed; task position still open

“Make a lesson plan for high-school Math students.”

This version omits “me,” yet it carries no more role, evidence, receiver, or classroom detail. Grade, standard, learning evidence, local context, access needs, and receiving educator remain open. Omitting one surface cue is not referent resolution. Research on prompt underspecification finds that inferred defaults can be fragile across model or prompt changes.[6]

Anchored · inspectable

Task position named

“Draft a Grade 9 statistics lesson plan for an educator teaching 28 students. Align the draft to the named standard, distinguish association from causation, label every data source, and return revision questions to the educator.”

The task position and receiver are explicit. The educator still decides fit, adaptation, and classroom use.

Read these as an orientation comparison. The third packet changes several work-bearing fields. A controlled local test changes one field at a time, holds the model configuration and source packet steady, and records the model’s questions or inferences for a named educator to review.

Test drive · working prompt capsule · seven equal conditions

II. Test-drive the Open Lesson Field and inspect what changes

The Open Lesson Field carries the practice into a Grade 9 statistics-planning situation. An educator can shape classroom conditions, align a CCSS-M goal, assign each source a role, anchor consequential references, rotate register, compare lesson routes, and return one prompt capsule to named reviewers. All prototype computation stays inside the embedded file, and human reviewers retain curriculum, evidence, and classroom authority.

Working prompt capsule · synchronized local draft

Each choice travels with the collaboration.

As details change, the instrument builds a local working prompt capsule from the current classroom, standards, source, reference, register, investigation, route, and receiver conditions. A written consequence cue beside each control names the lesson views and capsule fields that change; the companion boundary cue names the conditions that remain steady. The working capsule stays synchronized with those choices. When the review conditions are ready, Assemble reviewed prompt capsule records a distinct handoff revision that a named human can inspect with its included-change receipt, restore, print, or carry forward.

Teaching situation · work-bearing scale

A learner count becomes useful when it changes the plan.

“28 learners” is a class-level operating condition rather than a description of individual learners. Its value appears when the collaboration traces the number into observable preparation, participation, and review choices. In this field, 28 can inform:

  • Grouping: 14 pairs, 7 groups of four, or another educator-selected structure.
  • Materials: 28 individual copies, 14 paired sets, or 7 group packets.
  • Participation: the opportunity for each learner to speak, annotate, calculate, or submit an observation.
  • Reporting time: a whole-class share route that fits the available minutes.
  • Role distribution: recorder, plot reader, evidence checker, questioner, and reporter roles that can rotate.
  • Technology access: an explicit device arrangement by learner, pair, group, or station.
  • Educator movement: an observation and support route matched to the grouping pattern.
  • Evidence collection: 28 individual notes, 14 paired plots, or 7 group claims with individual reflection.
  • Room configuration: pair, table-group, or station movement that fits the available space.
  • Access conditions: turn-taking, noise, visual access, response modes, and peer-support choices for educator review.

One inspectable chain: 28 learners → 14 pairs → 14 material sets → paired comparison → 28 individual evidence-boundary notes → educator review.

The count supplies no learner identities, readiness profiles, disability records, family context, or conclusions about pedagogical fit. Those conditions remain with the educator and their approved systems.

Collaboration-system map · deeper reference

III. Read the collaboration system behind the working capsule

After the test drive, the nine-move field makes the underlying collaboration system visible. When instructions, sources, tool output, and quoted commands share one context, provenance can blur. These moves keep task authority, source standing, human reference, sensitivity, intended use, and the human return route legible as the working capsule forms.

Deeper collaboration conditions · research basis

Carry reference, register, proxy status, and evidence standing as distinct fields.

The opening comparison supplies the test-drive orientation. These deeper distinctions support review when language, role framing, model behavior, or receiving authority can materially change the handoff.

Pronoun anchor

Name the consequential referent

“We approved this” becomes “the steering committee approved this” when approval standing matters. A pronoun can remain when every collaborator can recover the same referent. Pronoun-fidelity and ambiguity studies identify distraction and unresolved reference as conditions worth testing.[3][4]

Register

Set the interaction; keep evidence separate

Specify “calm instructional planning,” “plain-language review,” or another useful register. Register shapes presentation; it neither creates evidence nor confers authority. Preserve the writer’s language variety rather than asking a model to imitate a demographic dialect.[7]

Social proxy

Disclose the stand-in

Ask the system to inspect a draft for questions a named population may raise. Label that pass as a proxy for consideration, distinct from research with or representation by that population.

Three different mechanisms

A persona vector, a prompt persona, and a task position are different things.

Persona vector
An activation-space direction associated with a modeled behavioral trait in specific research settings.[8]
Prompt persona
A role or character frame written into an input. In the cited factual-question study, persona frames shifted prediction accuracy inconsistently and supplied no general performance benefit; they did not confer expertise, evidence, or lived identity.[9]
Task position
The named function, source standing, output register, and human receiver needed for this piece of work.

Start with task position. Treat a prompt persona as a testable framing choice when the role frame itself matters; record the changed behavior and keep evidence, authority, and lived identity separate.

Benchmark posture · bounded instrument

Mention-resolution research is a bounded instrument for receiving-collaboration design.

IdentifyMe found pronominal mentions harder than nominal mentions in its long-narrative evaluation, while a separate coreference study found that traditional formats and metrics capture only part of referential understanding.[1][2] RUFF found that one non-adversarial distractor sentence reduced pronoun fidelity substantially on average in its test set; AmbiCoref found that most evaluated coreference models changed little between ambiguous and unambiguous sentence pairs.[3][4]

First-person opinion framing, prompt underspecification, and language-variety handling expose adjacent conditions, each in bounded studies with particular models and tasks.[5][6][7] Together they support an explicit-referent test where meaning matters. The receiving-collaboration question stays local: can the receiving human recover the task, source, standing, assumptions, and revision route from the artifact itself?

IV. Name the state the result should create

Desired-state language gives the response an observable destination. Privacy, safety, factual, and authorization boundaries remain explicit and travel with the replacement state they require. Recent negation-neglect research concerns what models learn from negated training documents rather than an ordinary prompt-writing rule; it gives teams a reason to test negation-bearing transformations without treating every negation as a failure.[10]

Rung 1 · boundary without destination

Free-standing prohibition

“Do not make the answer punitive.”

The unwanted concept remains named while the desired register stays undefined.

Rung 2 · stable lexical direction

Lexicalized antonym

“Use a calm, non-punitive register.”

A familiar antonym supplies a more stable direction while the boundary remains visible.

Rung 3 · observable destination

Positive constitutive state

“The answer is calm, revisable, specific, and evidence-bounded.”

Named qualities give reviewers an inspectable target state.

Material boundary · replacement paired

Safety-bearing formulation

“Credentials remain outside the prompt; use the supplied redacted identifier.”

The exclusion retains its material meaning and the task receives a usable representation.

V. Compose the smallest packet that can change the decision

Context is a selected working set. Position, relevance, and signal density matter alongside window size (Liu et al., 2024 — Lost in the Middle).[11] The packet keeps the task, data, authority, uncertainty, and output form in distinct fields. 

prompt_packet:
  task: "the transformation, analysis, or question"
  object: "the material under examination"
  desired_state: "observable qualities the result should have"
  evidence_horizon: "sources or facts that may support claims"
  uncertainty: "unknown, disputed, or unavailable material"
  source_labels: "trusted, untrusted, quoted, or synthetic"
  referents: "named roles for consequential I, me, you, we, or they"
  register: "interaction qualities; separate from evidence and authority"
  social_proxy: "named audience considered; proxy status disclosed"
  boundaries: "privacy, authorization, factual, and scope limits"
  output_shape: "form, length, technical depth, and audience"
  receiver: "human role with standing for the next decision"

Model capacity changes the prompt budget.

For a smaller language model, compare compact modular context, concrete constraints, earned examples, and decomposed tasks in the deployed configuration. For a mixture-of-experts system, compare stable task vocabulary and representative prompt variants across language, format, topic, and configuration. The packet makes those local comparisons possible without assuming one wording exercises every route.

VI. Compare the option space before committing

A candidate field keeps multiple plausible routes available before selection. This exercise compares unordered routes through changed work, assumptions, route-changing observations, and receiving authority. The live lab also keeps two probability frames legibly separate: its primary Verbalized Sampling prompt asks a separately authorized AI workflow to generate five distinct responses and assign each a percentage relative to the full response distribution, with residual or unlisted mass disclosed; an optional second frame asks for an independent conditional event estimate for each authored route. The local artifact carries the request while leaving candidates and values open, and the receiving educator reviews the standing and classroom relevance of anything returned.[12]

Focalization — Directing attention toward what can change the named decision while keeping the wider context recoverable.

Working definition · decision-focused attention

Here, the educator’s route decision stays in focus while affected learners, alternate candidates, residual probability, and the evidence that could reopen selection remain available for review.

1 · Name the decision

State the outcome, receiving population, time horizon, deployed configuration, and human role with standing to decide.

2 · Enumerate candidates

Ask for three materially distinct routes with changed work, one key assumption, and one observation that would move the team to another route.

3 · Expose the frame

Ask what each route draws on, what remains outside the present view, and which observable evidence would change the comparison.

4 · Preserve the decision

Record the candidate set, selected route, reason for selection, and receiving human authority in the next handoff.

Task: compare three routes for the stated initiative.
Decision condition: a reviewable first increment reaches the receiving team within the stated horizon.
For each route provide:
  route name · changed work · key assumption · route-changing observation
  evidence being used · material outside the current view · accountable human receiver
Then recommend one conditional route and name the observation that would change it.

The candidate field is a collaboration instrument. Compare it on the team’s recurring work, let human authority govern selection, and preserve the observations that change the route.

VII. Apply it this week

Choose one prompt from the last seven days and run a fifteen-minute collaboration review.

1 · Mark the field

Underline the task, circle source material, name its standing, and identify any embedded command or sensitive detail.

2 · Rewrite the destination

Replace one prohibition-dominant line with the observable state the result should create. Preserve every safety-bearing exclusion beside its replacement.

3 · Resolve one reference

Replace a consequential “I,” “me,” “you,” “we,” or “they” with the intended person, role, group, or artifact. Let conversational pronouns remain where the referent is shared.

4 · Reduce the packet

Keep the object, stable constraints, selected evidence, open alternatives, uncertainty, register, output shape, and receiver. Move residue outside the active context.

5 · Compare before selecting

Ask for three candidates with changed work, one assumption, and one route-changing observation. Compare them before requesting a conditional recommendation.

6 · Write the receipt

Record the chosen route, rejected alternatives that may matter later, human owner, next evidence check, and recovery position.
