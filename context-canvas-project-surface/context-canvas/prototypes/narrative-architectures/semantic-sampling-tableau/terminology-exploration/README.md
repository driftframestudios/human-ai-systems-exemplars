# Narrative Sampling Tableau — Chimeric Prototype v0.1

Open `narrative-sampling-tableau-chimeric-prototype-v0.1.html` in a modern
browser.

The prototype is self-contained; all runtime dependencies travel in the HTML
document.

## Included surfaces

- probability-of-what and sampling-condition composer;
- state-derived Prompt Capsule in plain and skill-assisted GitHub Flavored
  Markdown, with exact copy and download controls;
- prototype-specific related collaboration loops;
- editable possibility fan-out;
- open-tail and missing-mode lane;
- common-scale probability and interval plot;
- dimensional-fit matrix and weighted comparison;
- formal statistical-fit boundary;
- methodological-gap records;
- run and version comparison;
- probability-shift hypotheses;
- decision record;
- seven-family, twenty-card Core Architecture routing palette;
- research and terminology routes;
- accessible table equivalents;
- JSON and JSON-LD exports.

## Seed state

The seed uses the Conation Motion naming exploration from the earlier planning
bundle. Its values are worked, uncalibrated planning estimates.

The active variant demonstrates a layered naming architecture in which
canonical, technical, display, and authored labels can remain separate.
