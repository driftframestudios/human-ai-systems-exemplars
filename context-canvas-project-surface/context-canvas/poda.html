Site Reading and Debrief PODA Companion

Purpose → Objectives → Discoverables → Activities

A PODA is a compact, revisable frame for carrying a cross-functional investment ask through an organization. It names why the work matters, which goals belong to this phase, what must become inspectable, and which activities will surface that learning. Evidence may revise any zone.

Outcomes are discovered through encounter; the artifact form follows the learning.

01 · Position against current practice

PODA keeps the reasoning chain available before activity becomes the plan

A visitor can bring a live initiative, separate its purpose from this phase’s objectives, name what must become discoverable, and then choose activities. The Registry practice companion adds review conditions, accountable readers, return dates, and an optional governing measure while preserving this page’s source-native Purpose → Objectives → Discoverables → Activities vocabulary.

Architecture beats — preserve orientation while evidence changes the route

Debrief

Four distinct zones, one revision loop

Purpose names the reason; Objectives name phase goals; Discoverables name what must become inspectable; Activities name the encounters that can surface it.

The Snag

Visible work begins before the frame settles

Objectives blur into activities and discoverables compress into expected outputs, making movement easy to report and learning hard to inspect.

The Read

The team needs shared semantic orientation

Reason, goals, learning surfaces, and work need separate names so collaborators can revise one without silently rewriting the others.

The Move

Connect every action to what it should reveal

Write all four zones; connect each activity to a discoverable and each discoverable to a route. Mark uncertain items as needing to surface.

The Cure

A living orientation replaces the frozen brief

Activities serve discoverables, AI collaborators receive a stable frame, and new evidence can revise the plan without severing continuity.

The Guidance

Ask what must become discoverable first

Before choosing a document, workflow, diagram, prototype, or path, name the surface the team needs to encounter and learn through.

Prompt-side correspondence — PODA becomes a bounded working packet

The Prompt-Side Conditions packet maps directly onto this frame: task and desired state orient Purpose and Objectives; evidence horizon, uncertainty, sources, boundaries, and output shape constrain Discoverables and Activities. Context is a selected working set, so source-labeled, decision-relevant material belongs near the active discoverable rather than in an undifferentiated context dump (Liu et al., 2024 — Lost in the Middle).

Verbalized Sampling belongs at the Discoverables edge. Generate a candidate set—with a rough named-outcome likelihood, key assumption, falsifier, and attentional frame—before selecting one Deliverable or route. A lone Deliverable before that candidate set is only a first sampling rung, not evidence that alternatives were exhausted (Zhang et al., 2025 — Verbalized Sampling).

01 · Orientation instrument

Four zones carry one revisable investment frame

The sequence works forward, while evidence can return to any zone. Separating objectives from activities prevents a task list from impersonating a goal. Naming discoverables preserves the learning field before the organization commits to a document, interface, system, or implementation path.

Purpose

Name the larger state

Why does the work matter, what does it support, and what should remain true over time?

Objectives

Name the goals for this phase

Which outcomes belong now, which need more evidence, and which should wait?

Discoverables

Name the inspectable surfaces

What must become visible before the team commits to an artifact or system form?

Activities

Name the work that surfaces learning

Which sessions, maps, examples, tests, prototypes, or reviews will expose those discoverables?

Inspect and revise the complete PODA relationship surface

The working companion keeps semantic identity, focus-view state, activity-to-discoverable links, statuses, and handoff routes legible together. The four-zone explanation and operating-contract table on this page remain a complete static account of the same relationship model.

Use it as-is for initiative orientation; invert open Discoverables into a research-plan generator; adapt population and evidence terms to an industry; extend it with organization-owned definitions; connect accepted routes to an artifact pipeline; or let a bounded AI harness return each new signal through the revision loop. In every mode, the four semantic zones and the accountable human decision remain stable.

02 · Organizational negotiation

Research is a cross-functional investment ask

A request for repeated access to installation engineers, molecular technologists, clinical coordinators, or another scarce specialist population consumes real operating capacity. The PODA makes that cost visible before it is incurred and joins it to the organizational ability the work is expected to purchase.

Expectation — Constraints on future inputs that define acceptable outputs.

Working definition · participation contract

Here, the collaboration lead constrains future participation requests by naming the ask, scope, return, and responsibility that make an output acceptable.

Investment

Name attention, access, and opportunity cost

State which populations participate, how often, through which activities, and what other work their time displaces.

Expectation

Tell people what follows

Explain why the work matters, what will be asked, which scope applies, and when participants will hear about movement.

Return

Name the ability purchased

Connect the investment to a clearer decision, inspectable workflow, reusable rule, safer handoff, or changed operating state.

03 · Revision and route

The frame remains useful after the first conversation

Each activity links to at least one discoverable. Each discoverable carries a next route when deeper work is needed. Items can be stable for now, assumed, in need of surfacing, disputed, ready to route, or revised. Out-of-scope findings retain a receiving surface, while urgent conditions can move directly into accountable work.
