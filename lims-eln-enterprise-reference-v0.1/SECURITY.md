# Security

Use synthetic fixtures in repository tests. Keep patient identifiers, vendor
credentials, tokens, tenant payloads, and production logs outside the pack.

Report suspected vulnerabilities through the repository owner’s private
security-reporting channel. Public issues are suitable for design questions
that contain no sensitive operational detail.

Adopting teams own threat modeling, identity and access review, key management,
network policy, dependency scanning, privacy review, retention, monitoring,
incident response, and validation of the configured environment.
