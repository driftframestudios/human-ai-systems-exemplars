## Two experiments

### Encoding comparison

Create one canonical semantic packet per case containing the same task,
context, accepted state, supplied results, and evidence/authority facts. Render
it as Markdown, JSON, and their combination. Record template version and
content hashes. A field-by-field equivalence check precedes model calls;
required facts retain their value, type, identity, and relationships in each
condition. Markdown structure can differ while supplied meaning stays equal.
The combined condition repeats the same facts in two encodings; its added
exposure and length are part of the treatment.

Keep task instructions, ordering policy, model settings, tool permissions,
and output budget fixed. Rotate condition order across paired trials. Record
actual bytes and the selected model tokenizer's token count. Preserve the
complete inputs rather than trimming different facts to equalize length.

### Contribution comparison

Compare the finished production capsule with two explicit ablations: the
readable account with its JSON removed, and exact state JSON with the same
receiving task but its explanatory/calculated account removed. Record which
facts each removal withholds. This tests information contribution, rather than
isolating formatting. A calculation that requires omitted derived results is
scored as an information-availability difference unless the tool condition
explicitly supplies an equivalent computation route.

## Grading and budget

Use a predeclared answer key derived from the public fixtures and independently
checked arithmetic. Score each dimension separately as 0 (material error),
1 (partial/qualified), or 2 (complete and faithful): field fidelity;
unit/status preservation; evidence/authority fidelity; answer completeness;
and useful next action. Count unsupported additions separately. Preserve exact
quotations supporting each score, and retain reviewer disagreements.

The proposed first external tranche is two jobs (zero/absence and accepted

The named model and a monetary ceiling remain human-held selections. The

## Stopping and return

Stop the tranche at its approved call/token/monetary limit, a material fixture
or equivalence defect, or an actionable repeated failure. Repair a fixture
before interpreting affected trials. A small inconclusive sample returns
continued observation rather than a universal format recommendation.

Report deterministic restoration separately from model understanding. A
successful JSON round-trip supports exact transfer; it leaves answer quality
to the receiving trials. Choose retain-full, scoped compact option, targeted

## Evidence context

[He et al., Does Prompt Formatting Have Any Impact on LLM Performance?](https://arxiv.org/abs/2411.10541)
reports format-sensitive results across its tested tasks and models. It
supports a local comparison rather than a universal JSON-first claim.

[Liu et al., Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/)
reports position-sensitive retrieval in its tested settings. This motivates
tracking information position and packet length; current investment tasks and
receiving models retain their own observation.

The repository's Prompt Capsule contract, prompt-side conditions reading, and
Strategy Canvas portable-handoff planning material supply the local context.
