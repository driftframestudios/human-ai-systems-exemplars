| State | Meaning | Fitting next action |
| --- | --- | --- |
| D | Discovery: source ownership or a named uncertainty remains open. | Read source or select the smallest discriminating observation. |
| R | Repair: a coherent owner change is being prepared. | Complete the batch; observe a named unresolved behavior when useful. |

case definitions, artifacts and runtime. Preserve still-matching evidence;
repeat a broad campaign when a material owner, assertion, scope uncertainty or
acceptance gate reopens it. Source-only edits can end at source review.

**affected-family** campaign after each coherent behavior-change batch, plus

second execution. Unknown timing, token cost, process memory and human effort

## Append-only record and review

Each JSONL line has `schemaVersion`, unique `eventId`, ISO UTC `recordedAt`,
`type`, `epoch`, `recordingClass`, and a typed payload. Types are `entry`,
`protocol-review`, `decision`, `outcome`, `adjudication`, `correction` and
`disposition`. `recordingClass` is `prospective`, `retrospective` or `administrative`.

Preserve prior bytes. Append a correction referencing its original event and
reason rather than rewriting history. A missing execution timestamp stays
unknown; it cannot establish prospective eligibility. The linked review records
its reviewer role, decision and SHA-256 protocol digest. A material protocol
change receives a new version/digest and review before new enrollment.

Public records carry repository-relative paths, public Issue/PR links, source
hashes, semantic event IDs and normalized results. Exact local captures, raw
logs, environment paths, headers, secrets and gated workspace routes stay with
their existing private/local evidence owner. The public ledger is the single
research return; receiving Issues link its accepted PR and disposition.

Read JSONL syntax, unique IDs, references and result arithmetic directly with
existing tools. Independent review checks eligibility and representative
positive, zero, censored, deferred and renewal classifications. These bounded
record checks need no browser, new runner or duplicate mathematical test suite.
